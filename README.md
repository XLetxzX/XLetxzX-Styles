# XLetxzX Styles 1.0 (Minecraft 1.21.11 / Fabric)

One mod file: `XLetxzX-Styles-1.0-1.21.11.jar` (needs Fabric API).
Menu key: Right Shift (change it under Options > Controls > Key Binds > Miscellaneous).

## Parts
- `menu/` (java, res) - the XLetxzX menu (Home with skin, Extras, Packs, Mods, looks, themes, backgrounds). Yarn names.
- `core/` (java, res) - all features (HUD modules, Spotify, tweaks, texture pack mixer, pixel editor, FPS boost, Discord). Mojang names.
- `merge/` - the fabric.mod.json and icon of the final jar.

## Build
Double click `BUILD.bat` (one folder up), or run `gradlew mergeJars`.
Result: `build/libs/XLetxzX-Styles-1.0-1.21.11.jar`.
